# backgammon-ai

Учебно-research нейросеть для **коротких нард** (классические backgammon) с
нестандартным обучением: фокус на **predictive coding / свободной энергии**,
без классического backprop (в процессе разбора).

Текущий этап — **инженерная обвязка**: детерминированная среда, честные кости,
валидатор ходов, и промашленный веб-мост (пользователь сам кидает кости через
интерфейс — чтобы не было ощущения «нейронка себе подкручивает»).

## Статус

- [x] uv-окружение (numpy, pytest, ruff)
- [x] `core/dice.py` — честные кости (детерм., seed)
- [x] `core/board.py` — позиция 24 пункта + бар + дом (старт коротких нард)
- [ ] `core/moves.py` — генератор/валидатор легальных ходов (в работе)
- [ ] `web/` — интерфейс «брось кости сам, введи через UI»
- [ ] `model/` — нейронка (predictive-coding опция обсуждается)

## Окружение

uv-based:
```
uv sync
ruff check core/
pytest tests/
```

## Позлить на сайт

Интерфейс должен дать пользователю самому брос кости НЕ вводить в модель —
среда детерминированная, нейронка только выбирает из легальных ходов.
