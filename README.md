# backgammon-ai

Учебно-research нейросеть для **коротких нард** (классические backgammon) с
нестандартным обучением: фокус на **predictive coding / свободной энергии** —
локальные обновления весов в духе «как мозг», минимизация энергии системы,
без классического backward как основного механизма.

Сейчас: инженерия ядра (детерминированная среда) **готова**; ML-часть начата
(value-сеть + TD(λ)-обучение; сперва backprop-plan база, потом PC/EP).

## Запуск

Разработка велась на VPS без torch; проект поднимается на **целевой машине**
(5060 Ti). Torch прописан в deps — на целевой достаточно:

```
uv sync          # поставит numpy/pytest/torch
uv run pytest    # ~14 тестов: среда, фичи, (ML — если torch)
uv run python -m pytest tests/test_ml_stack.py  # ML-смоук (прогон)
```

## Архитектура (ключевое)

- **Модель НЕ генерирует ходы.** `legal_moves(pos, roll)` строит все легальные
  варианты (движок), модель выбирает из них — невозможный ход исключён.
- **Честные кости** — отдельный источник; на сайте пользователь сможет сам
  вводить бросок (полное доверие, «нейронка не подкручивает»).
- **Фичи**: позиция всегда «со стороны ходящего» (знаки зеркалятся) — сеть не
  учит, чей ход; stable вход (293-d).
- **Обучение**: (1) TD(λ) + backprop — контрольная планка; (2) дальше —
  **контрастный Predictive Coding / Equilibrium Propagation** (локальные
  энергетические обновления, без глобального backward) — исследовательская часть.
